# VoxType 0.6.0 发布审计

日期：2026-07-07

## 版本号选择

本次从 `0.5.0` 升到 `0.6.0`。原因是设置页信息架构明显调整：多个低频参数被折叠为高级设置，隐私页从配置开关入口改为状态、上传边界和清理入口。该变化直接影响用户首次配置和日常维护体验，按项目版本策略属于 minor 体验发布。

## 审计范围

- API配置页：ASR provider、豆包/阿里云必要认证、大模型必要配置和测试入口保持可见；ASR 语言、阿里云地域/模型/WebSocket、LLM thinking 适配改为高级设置。
- 热词与提示词页：热词、场景上下文、最近上下文和自动热词候选保持优先展示；Prompt 模板和 `min_chars` 改为高级 Prompt 设置，LLM 参考预算保留在 `config.toml`。
- 选项页：备用触发方式和录音排障默认折叠，已启用、非默认或有校验错误时自动展开。
- 隐私与本地数据页：移除重复功能开关，改为状态、管理跳转和清理本地数据。
- 三语言文案、README、英文 README、Wiki 草稿、CHANGELOG 和版本元数据。

## 不变边界

- 不删除或迁移配置字段，不改变 Rust 默认值、配置模板和配置文件结构。
- 不改变 ASR provider 选择、豆包协议、阿里云 FunASR 协议、音频分片、最终包门禁、空识别失败态、LLM 触发条件、剪贴板输出、热键默认值、托盘行为或统计正文策略。
- 不新增依赖，不记录真实密钥、识别正文、热词、prompt、最近上下文正文、屏幕 OCR 正文或 Windows 用户名路径。

## 关键判断

- 低频字段隐藏后仍保留校验修复路径：高级区在相关字段有校验错误时自动展开。
- 隐私页不再直接改开关，避免“隐私说明”和“功能配置”重复；用户通过“管理设置”跳转到热词、API 或选项页修改。
- LLM 参考预算属于低频容量参数，普通用户不需要日常手动设置；当旧配置存在预算校验错误时，热词页会显示临时修复入口。
- 备用触发方式、录音排障默认折叠，但用户已开启或改成非默认值时会自动展开，避免隐藏正在生效的设置。

## 手工回归建议

- 新用户首次进入 API配置页，只需看到 ASR 服务商、认证字段和测试按钮即可完成 ASR 配置。
- 切换阿里云 FunASR，确认地域、模型、自定义 WebSocket 和语言提示可从高级区打开，测试按钮仍可用。
- 进入热词与提示词页，确认常用热词、场景上下文、最近上下文和自动候选优先展示，Prompt 模板在高级区。
- 启用鼠标中键、右 Alt、录音增益或静音自动停止后，回到选项页确认对应折叠区自动展开。
- 隐私与本地数据页只显示状态、管理设置和清理按钮；点击管理设置能跳到对应设置页。
