# VoxType release audit - 2026-05-09

本记录用于保存 `0.1.62` 发布前审计的非敏感结论。不要在审计记录中写入真实密钥、识别正文、屏幕 OCR 正文、热词、prompt、最近上下文、日志正文或本机用户名路径。

## 范围

- 移除热词、API 配置和选项页顶部重复的“配置状态 / 重新加载”卡片，保留页面正文分组。
- 首页“启动方式”合并到顶部语音卡片，统一主快捷键、鼠标中键和右 Alt 的展示尺寸。
- 修正首页和侧边栏录音状态圆点对齐。
- 屏幕 OCR 上下文增加轻量文本规整：合并中日韩字符之间的多余空格，不改英文、快捷键和代码路径间距。
- 版本号、CHANGELOG、发布检查和安装包产物。

## 结论

- 配置页重复头部已删除，不再保留无实际必要的 `SettingsToolbar` 组件和相关三语言文案。
- 首页启动方式展示仅改变布局，不改变主热键、鼠标中键、右 Alt 的默认策略或运行时逻辑。
- 屏幕 OCR 仍只作为本轮临时上下文进入 ASR 和可选 LLM；OCR 正文不写入日志、统计、诊断报告或配置文件。
- OCR 文本规整只删除两个中日韩字符之间的空格，例如 `屏 幕 OCR 上 下 文` 变为 `屏幕 OCR 上下文`，保留 `Ctrl + Q`、`VoxType main` 等英文和符号间距。
- ASR 上下文拼接测试通过，屏幕 OCR 项在 `context_data` 达到上限时仍会保留。
- LLM prompt 拼接测试通过，OCR 上下文被标记为参考上下文，不是待润色文本，也不是用户指令。
- 使用本地 LLM 配置做过非敏感合成验证：OCR 上下文中的 `Akamai Quant` 和 `realtime/selection.py` 能被用于纠正输出。
- `npm run audit:npm` 通过，未发现 npm 漏洞。
- `npm run ai:release-check` 通过；Rust 审计仅报告当前 Tauri 依赖链中已允许的 warnings。
- `npx tauri build` 已生成 Windows x64 NSIS 安装包：`VoxType_0.1.62_x64-setup.exe`。
- 安装包 SHA256：`3B17F4F1E9EADF3BF489F89A2C95AC06585B122D78915E5E98399D9BF9768FE5`。
