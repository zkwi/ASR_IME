# VoxType 0.12.1 serde_with 安全补丁发布审计

日期：2026-08-10

## 版本判断

本次从 `0.12.0` 升到 `0.12.1`。只修复已发布锁文件中的一个间接依赖安全告警，不新增功能、不改变配置或用户交互，按版本策略递增 patch。

## 告警与影响判断

- GitHub Dependabot 告警：`GHSA-7gcf-g7xr-8hxj`，moderate，CVSS 5.1。
- 受影响版本：`serde_with <3.21.0`；修复版本：`3.21.0`。
- 问题是 `KeyValueMap` 序列化空序列或空映射项时可发生整数下溢并 panic；前提是应用通过该适配器序列化攻击者可控数据，影响为本地拒绝服务。
- VoxType 未直接调用 `serde_with::KeyValueMap`，但 `serde_with 3.18.0` 经 `tauri-utils 2.9.3` 进入 `x86_64-pc-windows-msvc` 依赖树。由于存在兼容的已修复版本，本次不以可达性不明确为由接受风险。

## 修改范围

- `src-tauri/Cargo.lock`：`serde_with` 与 `serde_with_macros` 从 `3.18.0` 升到 `3.21.0`，按上游依赖增加 `bs58 0.5.1`。
- 同步 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 中的应用包、`src-tauri/tauri.conf.json` 到 `0.12.1`。
- 同步 `CHANGELOG.md`、审计记录与文档索引。
- 不修改任何 Rust/TypeScript/Svelte 运行时代码，不改变 Tauri、ASR、LLM 或 Windows API 直接依赖版本。

## 主链路与隐私

- 录音、ASR 中间/最终包、LLM 资格、剪贴板、热键、托盘、统计和更新器逻辑均不变。
