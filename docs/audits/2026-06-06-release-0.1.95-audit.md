# VoxType release audit - 2026-06-06

Version: 0.1.95

## Scope

- Fixed recording overlay feedback so the user sees a startup state immediately, then the listening state only after the microphone is ready.
- Reworked ASR audio sending so pacing waits do not block WebSocket response polling.
- Kept actual ASR packet sizes within Doubao's documented 100-200ms range, with the default 200ms packet size preserved.
- Sent packets according to each packet's actual PCM duration, so 100ms leading/trailing silence pads and partial tail chunks are not stretched by the default packet interval.
- Sent the final audio packet as the negative final packet instead of adding a separate empty negative packet after audio.
- Synced README, English README, config example, Wiki drafts, changelog, version metadata, and ASR delivery audit notes.
