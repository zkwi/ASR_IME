## Changes

- Optimized the default LLM polishing prompt structure for voice input, including clearer boundaries, polishing goals, finance-oriented numeric formatting, and final punctuation handling.
- Added finance and investment examples for normalized numeric output such as `100万`, `1%`, and `10%`, while keeping the prompt from answering questions or calculating results.
- Expanded README, English README, Wiki drafts, and the example config with practical Doubao ASR setup guidance, optional LLM configuration notes, test-entry instructions, and common failure checks.
- Updated version metadata and changelog for the `0.1.76` release.
