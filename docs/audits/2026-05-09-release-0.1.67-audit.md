本记录用于保存 `0.1.67` 发布前审计的非敏感结论。不要在审计记录中写入真实密钥、识别正文、屏幕 OCR 正文、热词、prompt、最近上下文、日志正文或本机用户名路径。

## 结论

- 隐私页已补充配置文件与密钥、日志与诊断报告的本地保存和上传边界；页面仍只展示状态、计数、逻辑路径和说明，不展示识别正文、OCR 正文、热词历史正文、prompt 或密钥。
- 自动热词历史显示条数与近似字数，清理按钮在状态未读取前不可点，避免用户误判清理是否可执行。
- 最近上下文和 LLM 润色这类涉及正文或第三方服务的开关保留显式提示；LLM API 不完整时会引导用户先配置 API。
- 左侧导航的首页和 API 图标更贴近日常语义，当前页和键盘焦点更清楚；短窗口下侧栏可滚动，配置入口不会被底部状态卡遮住。
- 标题栏会显示设置待保存、保存中和已保存状态，降低自动保存模式下的不确定感。
- 本次不改配置结构、ASR 请求协议、LLM 润色触发条件、剪贴板输出策略、热键默认值、统计正文记录或日志脱敏策略。

- `npm run audit:npm` 未发现 npm 漏洞。
