## Changes

- 大模型 API 配置区默认直接展示 Base URL、API Key、模型名和测试按钮，不再需要展开配置。
- 大模型 API 字段新增就地提示，强调 Base URL、API Key 和模型名需要来自同一大模型服务商及地域，并提示不要误填豆包 ASR Access Key。
- 默认大模型提示词补充明显错词漏字、语法残缺和不通顺语句的修正规则，同时保留不新增事实、无法确定原意时保留原文的边界。
- README、英文 README、Wiki 草稿和配置样例同步更新默认提示词与配置体验说明。
