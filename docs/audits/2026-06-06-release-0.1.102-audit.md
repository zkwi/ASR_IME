# VoxType release audit - 2026-06-06

Version: 0.1.102

## Scope

- Fix final text selection when Doubao's final package adds missing tail words while slightly rewriting earlier text compared with `definite=true` segments.
- Keep final output gated on Doubao's final package; live captions and interim ASR packets remain feedback only.
- Add regression coverage for the tail-word recovery case and for rejecting unrelated longer final-package text.
- Sync README, English README, Wiki drafts, changelog, and version metadata.

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Final output still requires Doubao's final package; the fix only changes how a complete final package is compared with final two-pass segments.
- Unrelated longer final-package text does not replace stable two-pass segments.
- This release does not change stop-tail timing, ASR packet segmentation, OCR timing, LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
