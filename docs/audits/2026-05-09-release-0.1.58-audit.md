## 结论

- 完整设置默认展开，普通用户更容易找到热词、API 和选项页里的常用配置；精简设置仍可隐藏低频配置。

- 首页不再直接承载触发开关，改为展示触发方式摘要并引导到选项页统一修改。
- 粘贴方式和恢复剪贴板已合并到输入结果区域，减少设置页分散面板。
