## Changes

- 停录后保留内部最短尾音采集窗口，仍检测到人声时继续等到安静或达到上限，减少点击结束后末尾发音被切断。
- 关闭麦克风前 flush 不足一片的尾部 PCM，避免最后几十到几百毫秒音频丢失。
- 发送 ASR 结束包前按正常分片追加短静音，帮助豆包二遍识别触发最终判停。
- 收到豆包最终包后增加短 settle 窗口，允许后续二遍修正覆盖缺尾结果。
- 最终包整段文本可在确认前缀一致时补齐 `definite=true` 分句尾部；前缀比较会忽略常见标点和空白差异。
- 多声道转单声道时避免左右声道相位抵消导致人声被平均成近似静音。
- 同步 README、英文 README、配置模板和 Wiki 草稿中的停录尾音策略说明。
