## Changes

- 收紧默认大模型提示词和参考信息拼接规则，明确用户词典、场景上下文、最近上下文和屏幕 OCR 不能把待润色文本没说的内容补进输出。
- 统一“润色时参考最近上下文”开关的排版和颜色，避免新增配置项在同组设置中过度突出。
- 将最终提示词预览从系统 alert 改为应用内弹窗，支持滚动查看、一键复制、点击遮罩关闭和 Esc 关闭。
- 同步三语言提示词预览文案、配置模板、README、英文 README、Wiki 草稿和架构说明。
