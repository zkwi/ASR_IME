# VoxType 0.7.4 发布审计

日期：2026-07-08

## 版本判断

本次从 `0.7.3` 升到 `0.7.4`。原因是本轮继续修复悬浮字幕显示体验：在保证两行可见的基础上，按真实文本区域宽高选择最大可用字号。改动不涉及配置迁移、ASR provider 协议、最终文本门禁、LLM 润色、剪贴板输出或统计数据结构，按版本策略递增 patch。

## 修复与改进

- 较长单行字幕如果带有逗号、顿号、空格等明显停顿断点，会在高度允许时拆成两行。
- 双行字幕不再固定使用 `16px`，而是在正常字幕字号上限内，按当前文本区域高度和每行宽度取最大可用字号。
- 如果切换到双行字号后文本重新塌成一行，会再次按语义断点或必要的均衡拆分生成两行。
- 低高度或极窄宽度仍保留兜底逻辑，避免为了两行显示导致文字裁切。

## 主链路审计

- 本次只改前端悬浮字幕显示布局。
- 实时字幕和中间包仍只用于显示反馈，不进入润色、粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败、最终包门禁、日志脱敏、统计不记录正文、最近上下文不写回配置的规则未变。
- 不新增或删除配置字段，不需要配置迁移。
