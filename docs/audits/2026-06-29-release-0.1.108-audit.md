# VoxType release audit - 2026-06-29

Version: 0.1.108

## Scope

- Ship the accuracy-first ASR defaults in the packaged app: `enable_accelerate_text = false`, `accelerate_score = 0`, and `enable_ddc = false`.
- Keep microphone input gain at `0 dB` by default and remove the automatic input-gain calibration command surface.
- Keep local silence auto-stop disabled by default with `silence_auto_stop_seconds = 0`.
- Keep manual microphone gain available for low-volume troubleshooting, with docs recommending only small `+3 dB` or `+6 dB` adjustments after checking system microphone volume and distance.
- Sync Rust defaults, frontend fallback defaults, `config.example.toml`, README files, Wiki drafts, i18n text, changelog, version metadata, and release documentation.

## Verification

- `npm run ai:release-check`
- `npx tauri build`

`npm run ai:release-check` passed with 185 Rust tests. `cargo audit` reported only the existing allowed upstream warnings in the Tauri dependency chain.

## Main Flow Guardrails

- Final output still requires Doubao's final package; realtime and intermediate ASR text remain display feedback only.
- This release does not change ASR audio packet timing; the default audio segment remains `200ms` within Doubao's recommended `100-200ms` range.
- The packaged app no longer exposes an automatic microphone gain calibration command from the Tauri invoke surface.
- Manual `audio.input_gain_db` still applies only to local PCM before ASR; it does not save audio or add new uploads.
- Recording quality diagnostics still contain only non-transcript metrics and are not written to the main statistics table.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, log redaction, or config field structure.
