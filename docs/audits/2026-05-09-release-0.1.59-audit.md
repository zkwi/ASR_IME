# VoxType release audit - 2026-05-09

本记录用于保存 `0.1.59` 发布前审计的非敏感结论。不要在审计记录中写入真实密钥、识别正文、热词、prompt、最近上下文、日志正文或本机用户名路径。

## 范围

- 设置页继续精简：移除完整/精简/收起低频设置切换入口。
- 将 Resource ID、ASR/LLM 超时、字幕自定义尺寸/位置/颜色、主热键启用开关和录音时静音系统音量保留到 `config.toml`。
- 保留界面中更常用或排障价值更高的设置：ASR 语言、LLM API、热词、场景上下文、自动热词、粘贴方式、备用触发、低音量自动停止、字幕预设和透明度。
- 版本号、CHANGELOG、README、英文 README、Wiki 草稿和配置模板一致性。
- 发布前本地检查、密钥扫描、依赖审计和构建产物。

## 结论

- 设置页不再出现“完整设置 / 精简设置 / 收起低频设置”入口，默认可见项按页面固定展示。
- API 配置页只保留普通用户需要填写或测试的 ASR/LLM 项；Resource ID 和底层超时仍可通过配置文件修改。
- 热词页直接展示上下文、最近上下文和自动热词，避免低频但实用的能力被折叠隐藏。
- 选项页隐藏更偏底层的字幕细调和系统静音开关，保留可理解、可回退的常用设置。
- 本次改动不改变配置结构、默认值、ASR 请求、LLM 润色触发条件、剪贴板输出、热键默认策略、托盘、统计正文记录或日志脱敏。
- 未新增依赖，未发现被 Git 跟踪的本地配置、日志、统计、最近上下文或自动热词历史文件。
- 浏览器自动化覆盖简体中文、繁体中文和英文，在 1280x760、980x720 下检查热词与提示词、API 配置和选项页，未发现横向溢出、隐藏项文案残留或关键控件越界。
