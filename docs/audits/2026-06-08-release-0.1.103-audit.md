# VoxType release audit - 2026-06-08

Version: 0.1.103

## Scope

- Fix final-package extraction so final paste prefers Doubao final `result.text`, while live captions can still prefer fuller `utterances` text for responsiveness.
- Add regression coverage for the case where final `result.text` contains the tail word but `utterances` text is longer and still missing that tail word.
- Increase default stop-tail capture from about `100ms` to about `150ms`, capped at about `300ms` when voice remains recent.
- Migrate old default `stop_grace_ms` values `800`, `200`, and `100` to the new `150` default.
- Sync README, English README, config example, Wiki drafts, ASR guardrails, changelog, version metadata, and release documentation.

## Verification

- `cargo test asr::tests::final_text_prefers_full_result_text_even_when_utterances_are_longer`
- `cargo test asr::tests`
- `cargo test asr_ws::tests`
- `npm run ai:release-check`
- `npx tauri build`

## Main Flow Guardrails

- Final output still requires Doubao's final package; interim ASR text remains feedback only.
- Live captions still use the faster display extractor and can prefer fuller utterance text in the same response.
- Final paste now prefers final-package `result.text`, using utterances only when `result.text` is empty.
- The default ASR packet size remains `200ms` and stays within Doubao's recommended `100-200ms` range.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, log redaction, or config field structure.
