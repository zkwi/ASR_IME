# VoxType release audit - 2026-06-09

Version: 0.1.105

## Scope

- Change manual stop-tail capture to a fixed real-audio wait, defaulting to about `250ms`, without using local recent-volume detection to extend or shorten the tail.
- Remove the dedicated recent-volume tail-decision path from microphone capture; the volume level remains available for UI and optional silence auto-stop.
- Disable local silence auto-stop by default with `silence_auto_stop_seconds = 0`.
- Migrate old default silence auto-stop values `10` and `30` to `0`, while preserving user-set non-default values.
- Sync README, English README, config example, Wiki drafts, ASR guardrails, audio-fragment audit, changelog, version metadata, and release documentation.

## Main Flow Guardrails

- Final output still requires Doubao's final package; interim ASR text remains feedback only.
- Manual stop captures real tail audio for a deterministic window, then flushes partial PCM and sends the last real audio packet as the negative final packet.
- No trailing silence is appended after recording stops.
- The default ASR packet size remains `200ms` and stays within Doubao's recommended `100-200ms` range.
- Low-volume microphones no longer affect manual stop-tail duration through local volume detection.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, log redaction, or config field structure.
