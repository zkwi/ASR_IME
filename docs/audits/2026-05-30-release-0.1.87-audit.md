## Changes

- 发布已测试确认的默认 LLM 长详细提示词方案，作为新安装和恢复默认提示词时的推荐配置。
- 默认 System Prompt 区分短文本和长文本：短文本轻量纠错，长文本可删除口水词、重复、自我修正过程，并按最终意图整理结构。
- 默认 User Prompt Template 保留待润色文本边界，并增加紧凑当前请求提醒，降低长文本保留改口过程和技术文本被主动加 Markdown/反引号的概率。
- 配置模板、前端默认值、README、英文 README、Wiki 草稿和提示词长度对比审计记录已同步。
- 本地 VoxType 配置已同步新的默认 prompt，并保留本地备份文件。

## Verification

- `cargo test default_llm_prompts_are_ready_for_voice_input --lib` passed.
- Prompt length comparison used the same local model/config and synthetic samples; the long detailed prompt had the best quality and was retained.
- `npm run ai:release-check` passed, including frontend check/build, stats tests, secret scans, governance checks, Rust fmt/check/tests, Rust audit, clippy, and Tauri debug build.
- `npm audit --registry=https://registry.npmjs.org` passed with 0 vulnerabilities.
