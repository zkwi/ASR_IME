## 结论

- API 配置页会先展示“三步完成首次配置”，引导普通用户按“填写 ASR 密钥、测试连接、回首页开始输入”的顺序完成上手。
- 缺少 ASR 密钥时，自动进入 API 配置页顶部，不再直接滚过引导；点击“填写 ASR 密钥”仍会定位到密钥输入框。
- 首次配置引导在桌面和窄屏视口下均无横向溢出。
- 治理脚本新增三语言 i18n key parity 检查，覆盖嵌套文案对象，降低后续新增用户可见文案时漏同步的风险。

## 手工回归建议

- 清空或移除 ASR App Key / Access Key，确认主窗口自动进入 API 配置页顶部并展示三步首次配置引导。
- 点击“填写 ASR 密钥”，确认页面滚动到豆包认证输入区。
- 在 1280x780 和 640x760 左右窗口检查三步引导、健康检查、左侧导航和底部状态卡无横向溢出。
- 填写测试密钥后运行一次 ASR 连接测试；完成一次真实录音，确认识别、可选润色、粘贴、剪贴板恢复和统计刷新仍按原逻辑工作。
