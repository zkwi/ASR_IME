# VoxType 0.7.9 发布审计

日期：2026-07-11

## 版本判断

本次从 `0.7.8` 升到 `0.7.9`。`0.7.8` 已公开发布且标签保持不可变；其 GitHub runner 使用 Rust/Clippy 1.97，新增的 `manual_filter` 检查发现一处既有代码写法。该问题不影响字幕功能或安装包运行，但会让远端 CI 失败，因此使用 patch 版本发布兼容热修。

## 修复内容

- 将日志脱敏函数中手写的 `Option::and_then` 条件转换替换为等价的 `Option::filter`。
- 不改变脱敏键值识别、引号处理、日志内容限制或任何用户可见行为。
- `0.7.9` 继续包含 `0.7.8` 的悬浮字幕最低双行高度和异常短中间包保护。

## 主链路与隐私审计

- 不改变 ASR 请求、实时字幕内容选择、最终包门禁、LLM 润色、剪贴板、热键、托盘或统计。
- 日志脱敏测试继续覆盖常见密钥形态、换行清理和用户目录路径，不新增日志字段。
- 不新增配置字段、依赖或配置迁移。
