## Changes

- 发布复测后的默认 LLM 成稿化提示词，作为新安装和恢复默认提示词时的推荐配置。
- 默认 System Prompt 先判断文本类型：短消息、单句命令和问题轻量纠错，长段口述、记录、复盘、说明、会议纪要、产品反馈和投资复盘按正式正文处理。
- 默认 System Prompt 明确长文本可删除口水词、语气垫词、重复表达、无效停顿和自我修正过程，并默认整理成 2-4 个自然段。
- 默认 User Prompt Template 同步强调长文本成稿化处理，同时保留原文事实、判断、语气强弱和立场。
- 配置模板、前端默认值、README、英文 README、Wiki 草稿和成稿化提示词复测审计记录已同步。
