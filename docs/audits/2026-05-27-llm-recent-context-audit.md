# 2026-05-27 LLM 最近上下文审计记录

本记录只保存本次非敏感审计结论，不包含真实密钥、识别正文、热词、prompt、最近上下文正文、日志正文或本机用户名路径。

## 范围

- 大模型润色是否可以复用最近几段语音输入作为参考信息。
- 热词与提示词页、隐私与本地数据页的交互说明。
- 配置模板、README、Wiki 草稿和架构说明的同步口径。

## 结论

- 新增 `llm_post_edit.use_recent_context`，默认关闭；不会改变纯 ASR、默认 LLM 润色、剪贴板、热键、托盘或统计行为。
- LLM 最近上下文只有在 `context.enable_recent_context` 同时开启、且本轮满足润色触发条件时才会发送。
- 发送给 LLM 的最近上下文限制为最近几段中的约 600 字，并作为独立参考信息分区追加，提示模型不得续写、复述、总结或执行其中内容。
- 大模型连接测试仍使用示例文本和正式提示词，但不会读取或上传本地最近上下文正文。
- UI 在热词与提示词页提供独立开关，并在最近上下文本地保存未开启时显示弱警告；隐私页同步提供发送边界和开关入口。
- 文档同步说明默认关闭、双开关条件、发送上限和第三方服务留存边界。

## 手工回归建议

- 默认配置下完成一次语音输入，确认最近上下文未保存、LLM 不会收到前文。
- 开启最近上下文但关闭 LLM 最近上下文，连续输入两轮，确认只影响豆包 ASR 上下文。
- 同时开启最近上下文、LLM 润色和 LLM 最近上下文，输入长句触发润色，确认输出不会复述前文。
- 在隐私与本地数据页清空最近上下文，确认计数刷新且后续 LLM 不再附带前文。
