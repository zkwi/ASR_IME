# VoxType 0.4.3 发布审计

日期：2026-07-03

## 版本号选择

本次从 `0.4.2` 升到 `0.4.3`。原因是本轮主要修复配置迁移和保存链路问题，没有新增用户可见功能，也没有破坏性配置结构变化，按项目版本策略属于 patch 热修。

## 审计范围

按用户要求扩大到最近约 15 个提交，重点覆盖：

- 配置默认值和旧配置迁移。
- 麦克风设备选择、同名设备和默认设备回退。
- LLM 润色触发长度、DDC 默认值和测试请求。
- OCR 上下文捕获、等待和压缩。
- Tauri command 拆分后的注册完整性。
- 前端 controller 拆分后的命令调用和状态事件。
- 安装版本地配置、日志路径和诊断脱敏。

## 发现与修复

- 移除剩余按数值猜旧默认的迁移，避免自动热词历史上限、静音自动停止、静音阈值、停录尾音窗口和首字加速配置被误覆盖。
- 修复配置保存的二次校验问题：未改动的隐藏高级字段越界不再阻断普通设置保存；可见字段或已改动字段错误仍保持阻断。

## 未发现新增问题

- 前端调用的真实 Tauri 命令均已注册。
- ASR 空结果、最终包优先、连接异常失败态、诊断脱敏和最近上下文外置存储仍有现有测试覆盖。
- DDC 默认开启、`min_chars = 40`、最近上下文默认关闭、右 Alt/鼠标中键默认关闭等默认策略保持不变。

## 验证计划

- `cargo test commands::config_commands::tests`
- `cargo test config::tests`
- `npm run ai:check`
- `npm run ai:release-check`

## 手工回归建议

- 旧配置中保留隐藏高级越界字段，只修改一个普通设置并保存，确认不再失败。
- 旧配置中设置和旧默认相同的合法值，启动或保存后确认不被改写。
- 同名麦克风场景下选择 `0: Microphone` 和另一个同名设备，确认下拉框展示和实际录音设备一致。
