# VoxType 0.7.0 发布审计

日期：2026-07-07

## 版本判断

本次从 `0.6.4` 升到 `0.7.0`。原因是本轮包含两类明确用户可见行为变化：大模型配置保存后自动重新进行思考适配测速，以及录音兜底策略从本地音量静音判断切换为 ASR 无有效反馈判断。按版本策略，这不是单纯维护 patch，适合升 minor。

## 改动范围

- 大模型 Base URL、API Key、模型名或 thinking 开关保存后，自动从 `auto` 候选重新测试思考/推理关闭策略，并保存最快成功结果。
- 废弃旧的本地低音量静音自动停止，新增 `[asr].no_feedback_auto_stop_seconds = 30`，由 session 层统一执行 ASR 无有效反馈自动停止。
- 豆包和阿里云 ASR provider 只在非空文本、稳定分句或最终文本出现时上报有效反馈，空事件不会刷新无反馈计时。
- 同步 README、英文 README、Wiki 草稿、配置模板、三语言文案、CHANGELOG 和版本号。

## 主链路审计

- 空识别仍进入失败态，不会触发润色、粘贴或成功统计。
- 豆包最终输出仍等待最终包；阿里云最终输出仍等待 `task-finished`。
- ASR 无反馈超时复用 `stop_generation_with_grace`，保留停录尾音、flush 和最终包等待。
- 大模型自动适配测试不读取最近上下文正文，只使用内置连接测试样例。
- 本次未改变剪贴板恢复、热键默认值、统计正文禁写和日志脱敏策略。

## 配置兼容

- 新字段：`[asr].no_feedback_auto_stop_seconds`，默认 `30`，合法范围 `0..=300`，`0` 表示关闭。
- 旧字段 `audio.silence_auto_stop_seconds` 和 `audio.silence_level_threshold` 不再进入配置模型；旧配置加载时忽略，重新保存后不会写回。
- 版本号已同步到 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 和 `src-tauri/tauri.conf.json`。

## 验证结果

- `npm run ai:release-check`：通过。
- `npx tauri build`：通过。
- 生成安装包：`src-tauri/target/release/bundle/nsis/VoxType_0.7.0_x64-setup.exe`。

## 已知风险

- Rust audit 仍报告 Tauri 依赖链中的已允许 advisory warning，本次未新增相关依赖，release check 按现有策略通过。
- 大模型自动适配依赖网络和服务商响应；失败时保留当前配置，不阻断用户继续手动测试。
