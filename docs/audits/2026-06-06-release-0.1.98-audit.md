# VoxType release audit - 2026-06-06

Version: 0.1.98

## Scope

- Omit `audio.language` by default for Doubao `bigmodel_async + enable_nonstream` two-pass recognition; old `zh-CN` configs are treated as Auto/service default.
- Fail the current session on runtime microphone input-stream errors and invalidate the active ASR worker so incomplete audio cannot be polished, pasted, or counted.
- Prefer the system default input format when the requested capture format is unavailable, reducing driver instability and resampling pressure.
- Merge the 50ms leading-silence helper into the first real-audio packet: first packet about 150ms, later packets default 200ms, with no standalone 50ms packet and no silence packet when no real audio was captured.
- Sync README, English README, config example, Wiki drafts, changelog, i18n strings, frontend error actions, version metadata, and ASR delivery audit notes.

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- Runtime microphone capture errors now fail the session instead of producing low-quality partial transcripts.
- Captured tail audio is still flushed before the microphone is closed; no extra trailing silence is appended.
- No transcript text, hotwords, prompt content, recent context, screen OCR text, or secrets are written to logs or diagnostics.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
