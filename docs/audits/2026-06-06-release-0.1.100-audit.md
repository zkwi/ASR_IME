# VoxType release audit - 2026-06-06

Version: 0.1.100

## Scope

- Keep Doubao bidirectional streaming packets at the recommended default `200ms`, while merging the `50ms` leading-silence helper into the first configured-size packet instead of shortening it.
- Reduce local caption latency without changing ASR packet size: partial caption throttle is `50ms`, WebSocket response polling is `20ms`, and fast interim updates are coalesced to the latest text.
- Keep final output strict: live captions may use interim text, but polishing, clipboard, paste, recent context, hotword history, and stats still require Doubao's final package.
- Enable Doubao first-word acceleration by default with `accelerate_score = 8`; users can disable it or lower the score if first-word accuracy regresses.
- Align semantic smoothing with Doubao's documented default by making `enable_ddc` newly default to `false` while preserving explicit existing config values.
- Limit direct ASR hotwords to the first 100 effective entries, with manual hotwords before confirmed automatic hotwords, to avoid oversized real-time ASR requests.
- Sync README, English README, config example, Wiki drafts, changelog, version metadata, and ASR delivery audit notes.

## Verification

- `cargo test asr::tests`
- `npm run ai:release-check`
- `npx tauri build`

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- The default ASR audio packet size remains `200ms`; this release does not shorten packets to make captions appear faster.
- Stop tail capture defaults to about `200ms` and is capped at about `400ms`; no extra trailing silence is appended after recording stops.
- No transcript text, hotwords, prompt content, recent context, screen OCR text, or secrets are written to logs or diagnostics.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
