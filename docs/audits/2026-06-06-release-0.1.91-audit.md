## Changes

- ASR 最终输出只使用豆包 `definite=true` 的二遍识别分句，不再把实时中间结果作为成功输出兜底。
- 同一时间段的 `definite=true` 分句后续被服务端修正时，本地会用最新文本覆盖早期文本。
- ASR `result_type` 默认从 `full` 调整为 `single`，减少重复中间结果；旧默认 `full` 会在配置加载时自动迁移。
- 同步配置模板、前端兜底默认值、README 和 Wiki 草稿中的 ASR 最终文本说明。
