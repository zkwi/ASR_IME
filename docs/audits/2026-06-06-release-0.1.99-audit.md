# VoxType release audit - 2026-06-06

Version: 0.1.99

## Scope

- Added `audio.input_gain_db`, defaulting to `0 dB` so existing users keep the same recording behavior after upgrade.
- Applied microphone input gain after VoxType normalizes captured audio to Doubao-compatible `16000Hz`, mono, 16-bit PCM and before ASR packetization.
- Saturated boosted samples to the 16-bit PCM range to avoid integer overflow when users raise gain.
- Applied the same gain factor to local microphone level display, recent voice detection, and low-volume auto-stop so the UI and local stop logic match the audio sent to Doubao.
- Added Options UI in recording troubleshooting, validation range `-12..24 dB`, frontend defaults/types, three-language text, empty-recognition guidance, config template, README, and Wiki notes.

## Verification

- `cargo test audio::tests`
- `cargo test config::tests`
- `npm run check`
- `npm run ai:check`
- Release gate: `npm run ai:release-check`
- Release package: `npx tauri build`

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- Input gain only changes local PCM amplitude before ASR upload; it does not save audio or transcripts.
- This release does not change LLM post-edit trigger conditions, final-result selection, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or ASR packet timing.
