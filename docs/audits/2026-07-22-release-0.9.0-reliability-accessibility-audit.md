# VoxType 0.9.0 发布审计

日期：2026-07-22

## 版本判断

本次从 `0.8.3` 升到 `0.9.0`。改动覆盖配置加载与保存可靠性、关闭/退出保护、通知反馈、三语言状态、键盘可访问性、窄窗口与高 DPI 适配、敏感内存预览生命周期等多项用户可见体验，符合项目版本策略中“明显体验优化和持续多次改动后正式发布”优先升 minor 的条件。没有配置字段迁移、数据格式改变或安装路径变化，因此不升 major。

## 实现范围

- 配置加载明确区分未加载、已加载、文件缺失和读取失败；读取失败时不启用编辑，也不以默认配置触发自动保存。
- 自动保存状态明确区分待保存、保存中、已保存和失败；失败提示保持可见并提供重试。
- 窗口关闭与托盘退出在存在未解决保存失败时触发保护，可选择重试、放弃未保存修改或取消。
- 错误和需操作通知保持显示，普通信息与成功提示按策略自动收起；悬浮字幕后端只发状态码与兜底文本，前端按当前语言渲染。
- 关键设置字段补齐 `aria-invalid`、错误说明关联和首个错误聚焦；弹窗支持 Tab 循环、Esc 关闭与焦点恢复。
- 主窗口最低尺寸调整为 `960×640`，补充窄窗口样式和系统减少动画支持。
- 最近识别文本与 OCR 测试预览增加立即清空，并在隐藏窗口、退出或下一轮录音开始时清空内存状态。

## 主链路、配置与隐私审计

- 不修改 ASR 音频分片、最终包门禁、LLM 触发条件、粘贴成功判定、剪贴板恢复或成功统计规则。
- 悬浮字幕仍只显示实时文本、处理状态和错误，不新增“正在粘贴”“已粘贴”等瞬时状态。
- 不新增或迁移配置字段；只加强读取/保存失败时的前端状态与退出保护。
- 识别正文和 OCR 测试正文仅存在于前端内存预览，不写入日志、诊断报告或统计；新增生命周期清理不会把正文复制到其他存储。
- 不改变热键、托盘、最近上下文、系统静音等默认策略。

## TDD 与聚焦验证

- 配置持久化、通知策略、状态码映射、焦点索引和敏感预览生命周期均先添加失败测试，再完成最小实现。
- 定向 Vitest 覆盖配置状态、持久通知、状态码、Tab 环绕和录音阶段清理。
- Rust 单元测试覆盖配置退出保护与结构化悬浮字幕状态载荷。
- `npm run check` 与 `cargo check` 在实现批次结束后通过。
- Playwright 在 `960×640` 的 100%、150% 和 200% DPR，以及 `1366×768` 下完成页面验证：无横向溢出，六个主导航完整，关键配置字段错误关联有效。

## 建议手工回归

- 使用损坏或不可读的配置文件启动，确认设置页只读、错误保持显示、重试成功后才恢复编辑。
- 制造配置保存失败，分别验证重试成功、放弃修改、取消关闭，以及标题栏关闭和托盘退出入口。
- 仅用键盘完成 API 配置错误定位、弹窗 Tab 循环和 Esc 关闭，并确认关闭后焦点回到触发按钮。
- 在 100%、150%、200% Windows 缩放下回归 `960×640` 与常用窗口尺寸，确认标题栏、侧栏、设置表单和按钮不裁切。
- 产生最近识别文本和 OCR 测试预览，分别验证立即清空、隐藏到托盘和下一轮录音自动清空。

真实 ASR、LLM、剪贴板自动粘贴和托盘全路径仍建议在安装包上手工回归；自动测试不使用用户云端凭据，也不记录真实识别正文。
