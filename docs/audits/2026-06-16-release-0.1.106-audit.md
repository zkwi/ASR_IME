# VoxType release audit - 2026-06-16

Version: 0.1.106

## Scope

- Add a floating-caption UI configuration snapshot command for the overlay page.
- Cache the latest overlay UI config in the Rust overlay layer and use the saved config file as the primary snapshot source.
- Let the overlay page refresh its UI config on startup and periodically as a fallback, so opacity and color changes do not depend only on runtime events.
- Avoid reflowing long captions when the fallback config snapshot is unchanged.
- Sync changelog, version metadata, release checks, and release documentation.

## Verification

- Browser read-only verification confirmed `/?overlay=1` keeps transparent `html` and `body` backgrounds and computes caption background from CSS opacity variables.
- `npm run ai:check`
- `npm run ai:release-check`
- `npx tauri build`

## Main Flow Guardrails

- Live captions remain display feedback only; final output still requires Doubao's final package.
- This release does not change ASR request parameters, audio packet timing, LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, log redaction, or config field structure.
- The overlay still only shows realtime captions, elapsed/processing state, and user-facing errors; no paste-success transient text was added.
