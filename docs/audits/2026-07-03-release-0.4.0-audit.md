# VoxType 0.4.0 发布审计

日期：2026-07-03

## 发布范围

- 安装版配置默认改为 `%APPDATA%\VoxType\config.toml`，日志默认改为 `%LOCALAPPDATA%\VoxType\logs\voice_input.log`；开发模式继续使用仓库根目录文件。
- 安装版启动时如发现旧位置已有 VoxType `config.toml`，会提示用户复制迁移到新默认位置；隐私与本地数据页显示当前实际配置和日志路径。
- 拆分前端主 controller：会话状态、配置保存/自动保存、Tauri 原生事件监听、配置健康检查和测试流程分别收敛到独立 controller。
- 拆分 Rust Tauri command 入口：配置/测试、诊断与本地数据、更新、会话控制命令分别收敛到 `src-tauri/src/commands/`。
- 同步版本元数据、CHANGELOG 和发布审计记录。

## 版本号选择

- 本次包含安装版默认数据目录调整和旧配置迁移提示，属于用户可见行为变化，不是单纯 patch 修复。
- 同时包含前端 controller 与 Rust command 的结构治理，降低后续维护风险。
- 按版本号策略从 `0.3.0` 升到 `0.4.0`，避免对连续用户体验和工程治理改进过于保守。

## 主链路审计

- 不改变录音、豆包流式 ASR、LLM 润色、剪贴板写入、自动粘贴和统计链路。
- 空识别仍进入失败态，不触发润色、粘贴或成功统计。
- 最终输出仍等待豆包最终包；本次不调整 ASR 音频分片、尾音窗口或最终包选择策略。
- 配置迁移只复制旧 `config.toml` 到新默认位置，不写回最近上下文正文。
- 诊断报告与日志仍不包含识别正文、屏幕 OCR 正文、热词、Prompt、最近上下文正文、自动热词历史正文、候选词或密钥原文。

## 手工回归建议

- 安装版首次启动时，确认新配置路径为 `%APPDATA%\VoxType\config.toml`，日志路径为 `%LOCALAPPDATA%\VoxType\logs\voice_input.log`。
- 旧仓库目录或旧安装位置存在 VoxType `config.toml` 且新默认位置不存在时，确认启动迁移提示可复制旧配置。
- 打开隐私与本地数据页，确认展示的是当前实际配置和日志路径。
- 完成一次录音输入，确认 ASR、可选 LLM 润色、复制粘贴和统计仍按原链路执行。
- 打开诊断报告，确认路径已脱敏，且不包含识别正文、OCR 正文、热词、Prompt、最近上下文正文或密钥。
