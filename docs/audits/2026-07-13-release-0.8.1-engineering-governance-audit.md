# VoxType 0.8.1 发布审计

日期：2026-07-13

## 版本判断

本次从 `0.8.0` 升到 `0.8.1`。改动只增强发布诊断、版本与审计一致性检查、工程文档和注释，不改变用户功能、配置或主链路，按项目版本策略使用 patch 版本。

## 改进内容

- `ai:release-check` 在耗时检查开始前尝试独占打开调试版 EXE；若运行中的 VoxType 占用文件，会立即报告完整目标路径并提示关闭调试应用。
- 新增发布前置自测，覆盖构建产物不存在、正常可写和被进程独占三种情况，并纳入 `ai:check`。
- 治理检查把 `src-tauri/Cargo.lock` 纳入版本一致性，并要求当前版本存在发布审计且由 `docs/README.md` 索引。
- 系统审计 README、英文 README、8 个 Wiki 镜像、维护指南、代码规范、目录规范、当前实施计划与相关脚本注释；历史审计保持原始时间点结论。
- 统一测试口径：本地测试不访问服务商，ASR 连接测试使用真实凭据发送程序生成的短静音包，真实录音测试才会采集麦克风。

## 主链路、配置与隐私审计

- 不修改 ASR、LLM、录音、最终包、剪贴板、热键、托盘、统计或日志运行时代码。
- 不新增配置字段、配置迁移、依赖或用户可见设置。
- 测试不读取本机配置，不发送音频、正文、密钥、热词、prompt、OCR 或最近上下文。
- 发布前置诊断只检查仓库内调试构建产物的独占写权限，不枚举、终止或修改其他进程。
