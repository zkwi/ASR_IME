# VoxType 0.2.1 发布审计

日期：2026-07-03

## 发布范围

- 修复 LLM 润色触发长度计算：`min_chars` 不再直接按 Unicode 字符数判断。
- 新规则：中文等 CJK 字符按单字计；英文、数字和下划线组成的连续片段按 1 个单位计；空格、英文标点和常见中文标点不计。
- 默认 `min_chars = 100` 不变，配置结构不变；旧配置无需迁移。
- 同步三语言设置文案、配置模板、README、英文 README、Wiki、排障文档、架构说明和更新日志。

## 主链路审计

- 只改变是否触发 LLM 润色的长度判断，不改变 ASR 请求、最终包等待、剪贴板写入/恢复、热键、托盘或统计策略。
- 空识别仍进入失败态，不触发 LLM、粘贴、最近上下文、自动热词历史或成功统计。
- LLM 仍只有在已启用、触发长度达到 `min_chars`、Base URL、API Key 和模型名完整时才会调用。
- 日志只记录字符数和触发长度单位，不记录识别正文、OCR 正文、prompt、热词、最近上下文或密钥。

## 手工回归建议

- 中文 99 字不触发 LLM，100 字触发 LLM。
- 英文 99 个词左右不触发 LLM，100 个词左右触发 LLM。
- 单个很长英文单词或长串字母不应仅因为字母数达到 100 就触发 LLM。
- 包含路径、字段名、`Ctrl+V` 等技术文本时，连续英文片段应按词片段计，必要时仍能达到触发阈值。
