## 结论

- 主要页面文案将 ASR、LLM、OCR、Prompt、上传等工程化表达收敛为更普通的用户语言，降低首次使用理解成本。
- 隐私页保存位置统一使用应用全局字体，文件名和说明文字保持同一视觉系统。
- 首页和左侧导航移除左侧竖向选中标记，保留蓝色选中背景和图标高亮，视觉更简洁。
- 统计页按日数据在窄窗口下切换为带标签的卡片式布局，避免指标列挤出内容区。
- 本次不改配置结构、ASR 请求协议、LLM 润色触发条件、剪贴板输出策略、热键默认值、统计正文记录或日志脱敏策略。
