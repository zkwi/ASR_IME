# VoxType release audit - 2026-06-06

Version: 0.1.101

## Scope

- Shorten the default stop-tail capture from about `200ms` to about `100ms`.
- Reduce the stop-tail worst-case cap from about `400ms` to about `200ms` by aligning the internal minimum capture, quiet window, and max extra wait to `100ms`.
- Migrate both the old `800ms` default and the previous `200ms` default to the new `100ms` default on config load.
- Increase the default screen OCR context wait from `300ms` to `500ms`, matching recent local OCR timing better while still skipping timeouts.
- Keep Doubao first-word acceleration enabled by default with `accelerate_score = 8`.
- Sync Rust defaults, frontend fallback defaults, config example, README files, Wiki drafts, changelog, version metadata, and ASR delivery audit notes.

## Verification

- `cargo test config::tests`
- `cargo test session::tests`
- `npm run ai:release-check`
- `npx tauri build`

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- The default ASR audio packet size remains `200ms`; this release does not shorten ASR packet segmentation.
- Stop tail capture defaults to about `100ms` and is capped at about `200ms`; captured tail audio is still flushed before the microphone is closed.
- Screen OCR text remains runtime-only and is not written to logs, stats, or config files.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
