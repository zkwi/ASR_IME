# VoxType release audit - 2026-06-06

Version: 0.1.96

## Scope

- Reduced ASR leading and trailing helper silence to about 50ms each.
- Verified helper silence is only added at the start and end of the ASR audio queue; middle microphone chunks stay unchanged.
- Kept real ASR audio chunk sizing and pacing within Doubao's documented 100-200ms recommendation, with the default 200ms packet size preserved.
- Prioritized Doubao realtime cumulative text for floating captions while keeping final output gated on Doubao's final package.
- Avoided 1ms response polling after the final negative audio packet is sent.
- Reduced the default screen OCR context wait from 700ms to 300ms so optional context does not noticeably delay ASR connection startup.
- Synced README, English README, config example, Wiki drafts, changelog, version metadata, architecture notes, and ASR delivery audit notes.

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- All local captured audio is flushed before the microphone is closed; the last queued audio chunk is sent as the negative final packet.
- No transcript text, hotwords, prompt content, recent context, screen OCR text, or secrets are written to logs or diagnostics.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
