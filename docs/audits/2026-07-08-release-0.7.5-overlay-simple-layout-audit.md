# VoxType 0.7.5 发布审计

日期：2026-07-08

## 版本判断

本次从 `0.7.4` 升到 `0.7.5`。原因是修复悬浮字幕实时中间态显示问题，并将上一版偏复杂的双行排版逻辑收敛为更简单、可维护的规则。改动不涉及配置迁移、ASR provider 协议、最终文本门禁、LLM 润色、剪贴板输出或统计数据结构，按版本策略递增 patch。

## 修复与改进

- 悬浮字幕显示层会先压缩 ASR 中间态产生的多余空格：中文之间、中文标点前后的临时空格不再占显示宽度。
- 字幕布局规则收敛为短文本一行、长文本或实际换行时最多两行，不再按逗号、顿号等语义断点做复杂排版。
- 基础换行避免把句号、逗号等标点放到行首，减少实时字幕中第二行只有标点的坏状态。

## 主链路审计

- 本次只改前端悬浮字幕显示布局。
- 实时字幕和中间包仍只用于显示反馈，不进入润色、粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败、最终包门禁、日志脱敏、统计不记录正文、最近上下文不写回配置的规则未变。
- 不新增或删除配置字段，不需要配置迁移。
