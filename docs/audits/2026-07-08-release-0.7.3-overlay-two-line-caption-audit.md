# VoxType 0.7.3 发布审计

日期：2026-07-08

## 版本判断

本次从 `0.7.2` 升到 `0.7.3`。原因是本轮是聚焦悬浮字幕显示体验的修复，并补充前端布局回归测试；不涉及配置迁移、ASR provider 协议、最终文本门禁或破坏兼容行为，按版本策略递增 patch。

## 修复与改进

- 悬浮字幕短文本继续保持单行显示。
- 当实时字幕已经换成多行、或 ASR 中间结果带有换行符时，在字幕文本区域高度允许的情况下优先显示两行。
- 当用户把悬浮字幕高度调得过低、两行会低于最小可读字号时，自动退回单行滚动，避免文字被挤压或裁切。
- `overlayController` 使用真实文本容器高度重新计算布局，避免窗口高度和文本实际可用高度不一致导致误判。
- 新增 `scripts/test-overlay-layout.mjs`，覆盖显式换行、多行优先显示和低高度单行兜底，并接入 `npm run ai:check`。

## 主链路审计

- 本次不改 Rust ASR provider、音频采集、最终文本选择、LLM 润色、剪贴板输出、热键、托盘、统计或日志。
- 实时字幕和中间包仍只用于显示反馈，不进入润色、粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败、最终包门禁、日志脱敏、统计不记录正文、最近上下文不写回配置的规则未变。
- 本次不新增或删除配置字段，不需要配置迁移。

## 验证结果

- `npm run test:overlay`：通过。
- `npm run check`：通过。
- Playwright 浏览器验证：通过。`/?overlay=1` 中注入两行字幕后，两行文本都在字幕文本容器内可见。
- 内置 Browser 工具只用于尝试读取 overlay 页面；该工具本次 DOM 快照调用失败，后续改用常规 Playwright 完成可视化验证。
- `npm run ai:check`：通过。
- `npm run ai:release-check`：通过。
- `npx tauri build`：通过。
- 生成安装包：`src-tauri/target/release/bundle/nsis/VoxType_0.7.3_x64-setup.exe`。
