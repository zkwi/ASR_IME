# VoxType 0.2.0 发布审计

日期：2026-07-03

## 发布范围

- LLM 润色阈值默认调整为 `100` 字，旧默认 `25`、`40`、`80`、`120` 会迁移为 `100`。
- 豆包 ASR 语义顺滑 `enable_ddc` 默认开启；旧默认组合会随 LLM 阈值迁移一并开启，之后用户仍可手动关闭。
- 真实 LLM 润色请求按输入长度设置输出预算，短文本请求使用更小 `max_tokens`；StepFun 兼容分支继续不发送 `max_tokens`。
- LLM 配置页测试连接改用较长内置样例，测试更贴近日常长文本润色情况，且不读取最近上下文或用户识别正文。
- 版本策略更新为不再默认保守递增 patch；本次默认策略和体验优化集中发布，版本号选择 `0.2.0`。

## 链路审计

- 主链路仍等待豆包最终包；实时字幕和中间包不进入润色、粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败态、剪贴板写入失败兜底、自动恢复剪贴板、热键默认值和托盘行为未变更。
- DDC 默认开启只影响豆包 ASR 请求参数，不新增配置字段；用户显式关闭后不会被后续迁移反复打开。
- LLM 速度优化优先减少触发频率和输出预算，不把识别正文、OCR 内容、prompt、热词或最近上下文写入日志。

## 正式环境日志结论

- OCR 在抽样日志中不是主要瓶颈，单次耗时集中在数百毫秒级；失败或超时会跳过上下文，不应阻塞整体流程。
- 主要慢点集中在 LLM 润色阶段，慢请求可达到十秒级；短文本触发 LLM 会明显拉长 stop 到 paste 的体感等待。
- 因此本次选择“100 字以下依赖 ASR DDC，100 字以上再触发 LLM”的策略，减少短文本不必要的大模型调用。

## 手工回归建议

- 新安装配置：确认 DDC 默认开启、LLM 最小润色字数为 `100`。
- 旧默认配置迁移：确认旧 `enable_ddc=false` 且 LLM 阈值仍为旧默认时迁移到 DDC 开启、阈值 `100`。
- 用户显式关闭 DDC：保存后重启确认不会被迁移重新开启。
- 短文本输入：确认 100 字以下不显示“正在润色文本”，但 ASR 请求仍启用 DDC。
- 长文本输入：确认 100 字以上在 LLM 配置完整时进入润色，并能正常粘贴。
