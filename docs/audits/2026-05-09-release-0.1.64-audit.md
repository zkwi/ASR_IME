本记录用于保存 `0.1.64` 发布前审计的非敏感结论。不要在审计记录中写入真实密钥、识别正文、屏幕 OCR 正文、热词、prompt、最近上下文、日志正文或本机用户名路径。

## 范围

- 首页空闲、处理中、成功和错误状态的视觉层级。
- 首页顶部语音卡片、就绪提示、成功结果提示和输入表现卡片的对齐、间距与状态样式。
- 版本号、CHANGELOG、发布检查和安装包产物。

## 结论

- 首页展示层更紧凑，顶部语音卡片和输入表现区域在常用窗口尺寸下减少了不必要的外层卡片感。
- 首页卡片按内容区全宽对齐，避免宽屏窗口下出现过多居中留白。
- 刚启动且没有最近结果时，首页中间层显示就绪提示卡，保持与成功后页面一致的三段式结构。
- 处理中状态仅改变前端卡片样式，不改变录音、等待最终结果、LLM 润色、剪贴板输出或统计逻辑。
- 成功结果提示仍只在当前窗口临时保留识别文本；关闭窗口或开始下一次录音后清除，复制按钮沿用现有剪贴板命令。
- 本次不改配置结构、默认值、ASR 请求、LLM 触发条件、热键默认策略、托盘、统计正文记录或日志脱敏。

- `npx tauri build` 已生成 Windows x64 NSIS 安装包：`VoxType_0.1.64_x64-setup.exe`。
