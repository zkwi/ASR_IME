# VoxType release audit - 2026-06-06

Version: 0.1.94

## Scope

- Fixed ASR head/tail completeness by forcing Doubao `result_type=full`, keeping final package output only, and allowing the final full text to recover missing head or tail words when it covers the two-pass definitive text.
- Added leading silence before the first real audio packet and paced audio chunks at the documented 100-200ms interval.
- Ensured microphone capture is started before the recording overlay tells the user to speak.
- Kept PCM normalization and segmentation flush behavior so partial downsample windows, partial chunks, and incomplete channel frames are not dropped.
- Synced README, English README, config example, Wiki drafts, changelog, version metadata, and ASR delivery audit notes.

## Main Flow Guardrails

- Empty recognition still enters the failure flow and must not trigger polishing, paste, or success statistics.
- Live captions and interim ASR packets remain feedback only; final output requires Doubao's final package.
- No transcript text, hotwords, prompt content, recent context, screen OCR text, or secrets are written to logs or diagnostics.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, or config field structure.
