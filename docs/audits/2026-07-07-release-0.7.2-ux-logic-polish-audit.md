# VoxType 0.7.2 发布审计

日期：2026-07-07

## 版本判断

本次从 `0.7.1` 升到 `0.7.2`。原因是本轮主要是设置页 UX 修复、自动思考适配状态反馈和前端控制逻辑收敛，不涉及配置迁移、ASR 主链路变更或破坏兼容行为，按版本策略递增 patch。

## 修复与改进

- 修复大模型 Base URL、API Key 等配置错误可能跳转到 ASR 认证区域的问题；现在 LLM 配置类错误会定位到大模型 API 配置块。
- 大模型 API 区域新增思考适配测试状态，自动保存后可看到自动测试启动、成功延迟和策略保存结果。
- ASR 与大模型测试按钮文案拆分为具体动作，降低“测试”按钮含义不清的问题。
- 大模型自动测试说明补充数据边界：使用内置样例，不读取剪贴板、实时屏幕 OCR 或本地最近上下文正文。
- 将大模型自动适配的指纹、排队、手动测试和状态文案收拢到 `llmAutoAdaptController`，减少 `VoxTypeController` 中的跨模块副作用。

## 主链路审计

- 本次不改 Rust ASR provider、音频采集、最终文本门禁、LLM 请求体、剪贴板输出、热键、托盘、统计或日志。
- 空识别失败、最终包门禁、统计不记录正文、日志脱敏和最近上下文不写回配置的规则未变。
- 大模型自动适配仍只在 Base URL、API Key、模型名或 thinking 开关相关指纹变化且三项连接配置完整时触发。
