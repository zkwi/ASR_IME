# VoxType 0.3.0 发布审计

日期：2026-07-03

## 发布范围

- 正式 ASR 识别链路增加建连超时和异常重置：连接超时、连接失败、最终结果等待超时、连接提前关闭会返回不同错误码并进入失败态，下一次快捷键可重新开始。
- 麦克风选择优先按保存的设备名称匹配，旧数字 index 仅作兼容；保存的麦克风不可用时自动回退系统默认输入设备并显示非阻塞提示。
- 同步版本元数据、CHANGELOG 和发布审计记录。

## 版本号选择

- 本次不是单纯文档或小范围 UI 文案修复，包含主链路异常恢复、失败态复位和麦克风配置兼容策略。
- 改动直接影响正式识别成功率、恢复能力和设备切换后的可用性，属于明显用户可见体验修复。
- 按版本号策略从 `0.2.2` 升到 `0.3.0`，避免继续用 patch 低估这轮可靠性改进。

## 主链路审计

- 空识别仍进入失败态，不触发润色、粘贴或成功统计。
- 最终输出仍等待豆包最终包；连接失败、连接关闭和最终包超时只改变失败分类和恢复能力，不使用实时字幕兜底成功。
- ASR worker 失败后会使当前 generation 失效，避免旧任务继续覆盖下一轮录音状态。
- 麦克风设备不可用时只回退到系统默认输入设备并提示，不改变 ASR 分片默认值、LLM 阈值、剪贴板、热键、托盘或统计逻辑。
- 日志与诊断不新增识别正文、密钥、热词、prompt 或最近上下文正文。

## 手工回归建议

- 断网或 ASR 配置错误时，首页进入失败态并可通过下一次快捷键重新开始。
- 豆包连接提前关闭或最终包等待超时时，错误提示为对应 ASR 错误而不是卡在处理中。
- Windows 麦克风设备顺序变化后，已保存麦克风能按名称继续命中。
- 已保存麦克风被移除时，自动回退系统默认输入设备，并显示非阻塞提示。
