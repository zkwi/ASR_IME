## Changes

- 停录后必须等到豆包最终包才允许输出，连接提前结束或未返回完整最终结果时进入失败态，不再粘贴可能缺尾的中间文本。
- 主链路强制使用豆包二遍最终结果所需参数：开启二遍识别、开启 utterances、使用 `single` 增量返回，并关闭加速文本。
- 麦克风采集结果发送豆包前统一转换为 `16000Hz`、单声道、16-bit PCM。
- 16k 音频规范化使用简单窗口平均下采样，减少 48k/44.1k 转 16k 时因取点导致的语音能量丢失。
- 同步配置模板、README、英文 README 和 Wiki 草稿中的 ASR 最终结果与音频格式说明。
