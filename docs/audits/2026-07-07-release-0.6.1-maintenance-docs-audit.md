# VoxType 0.6.1 发布审计

日期：2026-07-07

## 版本号选择

本次从 `0.6.0` 升到 `0.6.1`。原因是本轮主要是维护性优化和代码文档质量改进：抽取重复 UI 组件、补充关键代码边界说明，并新增维护指南；没有新增用户功能、配置字段或默认策略变化，按版本策略属于 patch 发布。

## 审计范围

- 高级设置折叠面板：统一到 `AdvancedSettings.svelte`，减少 API配置、热词与提示词、选项页的重复 DOM/CSS。
- ASR provider 维护说明：补充 provider facade、阿里云最终文本门禁、前端 ASR 配置指纹和设置字段跳转的代码级说明。
- 维护文档：新增 `docs/maintenance-guide.md`，并从文档索引和架构概览接入。
- 版本元数据、CHANGELOG 和发布审计记录。

## 不变边界

- 不改变 ASR provider 选择、豆包协议、阿里云 FunASR 协议、音频采集、最终文本门禁、LLM 触发、剪贴板输出、热键、托盘、统计或日志脱敏行为。
- 不新增、不删除、不迁移配置字段。
- 不新增依赖。
- 不记录真实密钥、识别正文、热词、prompt、最近上下文正文、屏幕 OCR 正文或 Windows 用户名路径。

## 验证结果

- `npm run ai:check`：通过，包含前端构建、密钥扫描、治理检查、Rust fmt/check/test，Rust 单元测试 218 个通过。
- `npm run ai:release-check`：通过，包含本地检查、Rust audit、clippy 和 Tauri debug build；Rust audit 仅报告既有允许的上游 warning。
- `npx tauri build`：通过。

## 发布产物

- Windows x64 NSIS 安装包：
  `src-tauri/target/release/bundle/nsis/VoxType_0.6.1_x64-setup.exe`

## 手工回归建议

- 打开 API配置、热词与提示词、选项页，确认高级设置折叠区仍可展开/收起。
- 触发隐藏高级字段的校验错误时，确认设置页仍能跳到对应面板。
- 切换豆包/阿里云 provider 并执行连接测试，确认配置状态刷新逻辑不受文档性改动影响。
