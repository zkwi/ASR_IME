# VoxType 0.7.8 发布审计

日期：2026-07-11

## 版本判断

本次从 `0.7.7` 升到 `0.7.8`。改动修复悬浮字幕的两个边界缺陷，不改变配置字段、ASR provider 协议、最终文本门禁、LLM 润色、剪贴板输出或统计结构，按版本策略递增 patch。

## 修复与改进

- 悬浮字幕运行窗口使用 `52px` 最低有效高度，保证扣除上下内边距后仍能容纳两行最小字号文本。
- 新保存配置不再接受低于 `52px` 的高度；旧配置继续正常加载，运行时自动钳制，不回写用户配置文件。
- 同一轮录音内，已有较完整字幕不会再被明显异常的 1-4 字非重合中间包覆盖。
- 正常的较完整修订仍可更新字幕，不拼接不确定片段，不恢复滚动或历史布局状态。

## 主链路审计

- 本次只影响实时字幕反馈和悬浮窗口尺寸，不改变 ASR 请求、最终包等待、最终文本选择、LLM 润色、剪贴板输出、最近上下文、自动热词或统计逻辑。
- `LiveCaptionBuffer` 每次录音会话独立创建；最终 ASR 包仍绕过实时字幕保护并按原有门禁处理。
- 不新增日志字段，不输出识别正文、密钥、热词、prompt 或本地路径。
- 不新增或删除配置字段，不需要配置文件迁移。

## TDD 记录

- 高度钳制测试首次运行因 `effective_overlay_height` 不存在而编译失败，补充最小实现后通过。
- `51px` 配置校验测试首次运行因旧校验仍接受该值而失败，改用统一 `52px` 下限后通过。
- 非重合单字中间包测试首次运行因缓冲接受单字更新而失败，增加保守过滤后通过。
- 额外覆盖完整非重合修订，确认正常更新能力未被阻断。

## 远端 CI 说明

- `main` 和 `v0.7.8` 推送触发的 GitHub CI 均在 Rust/Clippy 1.97 的 `manual_filter` 新检查处失败，位置为既有日志脱敏代码，与本次字幕改动无关。
- 该兼容问题在 `0.7.9` 使用 Clippy 建议的等价写法修复；`0.7.8` 标签和 Release 保持不可变，不移动或覆盖。

## 建议手工回归

1. 使用正常窗口高度录入 19 字以上文本，确认稳定显示两行。
2. 临时使用旧配置 `height = 40` 启动一次录音，确认窗口自动具备两行高度且位置正常。
3. 连续口述较长内容，确认中间识别波动时不会突然只剩单字，同时最终粘贴文本不受影响。
