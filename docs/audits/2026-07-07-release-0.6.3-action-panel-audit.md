# VoxType 0.6.3 发布审计

日期：2026-07-07

## 版本号选择

本次从 `0.6.2` 升到 `0.6.3`。原因是本轮是代码维护性和 UI 交互一致性优化：抽取重复操作面板、减少页面本地 CSS，并统一窄窗口按钮换行行为；没有新增用户功能、配置字段或主链路行为变化，按版本策略属于 patch 发布。

## 本轮问题整理

- `OptionsSection.svelte` 内有多处重复的“标题 / 说明 / 元信息 + 操作按钮”卡片，DOM 和响应式 CSS 重复，后续维护容易样式漂移。
- 选项页中 OCR 测试、更新检查、诊断日志入口都使用 `update-card` 命名，语义偏窄，不利于后续复用。
- 首页音频质量提示和选项页操作入口本质上是同类交互，但原来各自维护布局和按钮响应式。
- `asr_ws.rs`、`config.rs`、`audio.rs` 等核心大文件仍偏大，但本轮改动目标包含 UI 交互优化；继续拆核心主链路会提高发布风险，因此本轮不触碰。

## 改动范围

- 新增 `src/lib/components/common/ActionPanel.svelte`，只封装通用布局、状态色和按钮响应式，不承载业务逻辑。
- 首页音频质量提示改用 `ActionPanel`，保留原来的提示条件、文案、排障入口和 `aria-live`。
- 选项页屏幕 OCR 测试、更新检查、诊断日志入口改用 `ActionPanel`。
- 删除选项页和首页对应的重复操作卡片 CSS。
- 更新维护指南，说明设置页同类操作卡片的复用边界。

## 不变边界

- 不改变 ASR provider、豆包协议、阿里云 FunASR 协议、音频采集、最终文本门禁、LLM 触发、剪贴板输出、热键、托盘、统计或日志脱敏行为。
- 不新增、不删除、不迁移配置字段。
- 不新增项目依赖。
- 不记录真实密钥、识别正文、热词、prompt、最近上下文正文、屏幕 OCR 正文或 Windows 用户名路径。

## 手工回归建议

- 打开首页，确认音频质量提示出现时排障按钮仍可点击。
- 打开选项页，滚动到屏幕文字上下文、更新与诊断区域，确认按钮布局不溢出。
- 做一次屏幕文字识别测试、检查更新、打开日志或复制诊断报告，确认入口仍能触发原有动作。
