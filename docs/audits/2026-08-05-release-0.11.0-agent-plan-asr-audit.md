# VoxType 0.11.0 火山方舟 Agent Plan ASR 发布审计

日期：2026-08-05

## 版本判断

本次从 `0.10.4` 升到 `0.11.0`。改动新增用户可见的豆包接入方式、配置字段、认证门禁、连接端点和设置界面，属于明确的新功能与设置结构扩展；不破坏旧配置，按项目版本策略升级 minor。

## 用户问题与实现结论

- 在保留豆包原有 App Key + Access Key 接入的基础上，新增火山方舟 Agent Plan ASR。
- API配置页提供明确选择器，不根据密钥形态自动猜测模式；两套凭据独立保存在本地，运行时只使用当前模式。
- Agent Plan 固定使用 `X-Api-Key`、`X-Api-Resource-Id: volc.seedasr.sauc.duration` 和 `wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_async`，不受标准模式自定义 WebSocket 地址影响；请求层也使用固定常量，手工编辑配置绕过保存校验时不会把其他资源发给服务端。
- 切换到 Agent Plan 时设置页自动校正固定 Resource ID；Rust 保存校验也会拒绝其他资源，避免控制台配置与请求计费资源不一致。
- 帮助文档按钮按当前豆包接入方式打开标准 ASR 或 Agent Plan 官方文档。本版本只增加 ASR，不接入 TTS，也不代替用户在方舟控制台开启模型或超额后付费。

## 主链路影响

- 改动位于豆包连接前的配置门禁、请求预览和 WebSocket 握手；录音会话、音频采集、二进制协议、最终文本选择、LLM、剪贴板和统计链路保持原实现。
- 标准豆包接入继续使用原请求地址及 `X-Api-App-Key`、`X-Api-Access-Key`、`X-Api-Resource-Id`，旧配置缺少 `auth.mode` 时默认迁移为 `app_access`。
- Agent Plan 与标准豆包继续共用 `200ms` 默认音频分片、二遍识别、`full` 累计结果和最终包门禁；实时字幕与中间包仍不能进入润色、粘贴、上下文、热词历史或成功统计。
- 空识别失败、停录尾音、剪贴板失败兜底和恢复原剪贴板策略均未修改。

## 配置、界面与文档

- Rust 与前端配置增加 `auth.mode` 和 `auth.api_key`，默认值、配置模板、字段校验、设置页、三语言文案和连接就绪判断同步更新。
- API配置页保留未选中模式的凭据，不要求用户切换时覆盖 Key；Agent Plan 专属 Key 默认隐藏并支持现有显示/复制交互。
- 同步更新中英文 README、Setup Guide、Feature Guide、Troubleshooting、ASR 守门清单和豆包参考文档说明。

## 隐私与安全

- 用户真实 Agent Plan API Key 仅写入 Git 已忽略的本地 `config.toml`，不进入代码、模板、测试、文档、统计或诊断报告。
- 日志脱敏新增无标签 `ark-` 密钥形态；握手成功只记录服务端 `X-Tt-Logid`，不记录请求头、API Key、识别正文、热词、Prompt、最近上下文或 Windows 用户名路径。
- 诊断报告通过统一 provider 门禁判断当前模式是否已配置，只输出布尔状态，不输出凭据内容。
