## Changes

- 精简默认大模型润色提示词和配置模板，保留“不聊天、不新增事实、金融数字谨慎处理”等核心约束，减少最终润色请求体积。
- 大模型润色和自动热词生成默认显式发送 `enable_thinking=false`；非阿里云兼容接口如果不支持该字段，会自动重试一次不带该字段的请求。
- 最终 LLM 润色请求不全局压低 `max_tokens`，避免 StepFun 等模型在第三方兼容接口下因输出预算过小返回空内容。
- 大模型 Base URL 支持根地址、`/v1` 和完整 `/v1/chat/completions` 等等价写法，润色测试、实际润色和自动热词生成共用同一规范化逻辑。
- README、英文 README、配置模板、Wiki 草稿和三语言设置文案同步说明简化提示词、关闭思考模式和 Base URL 等价写法。
