# VoxType 0.6.2 发布审计

日期：2026-07-07

## 版本号选择

本次从 `0.6.1` 升到 `0.6.2`。原因是本轮只修复 CI / npm 依赖审计和发布检查口径漂移，没有新增用户功能、配置字段或主链路行为变化，按版本策略属于 patch 发布。

## 审计范围

- 前端依赖审计：升级锁定 `vite` 到 `8.1.3`，清除 GitHub Actions 中 `npm audit` 报出的高危告警。
- 发布检查脚本：`npm run ai:release-check` 新增 `npm audit`，让本地发布检查覆盖 CI 中的依赖审计。
- CI 工作流：GitHub Actions 改为复用 `npm run ai:release-check`，减少本地和远端检查漂移。
- 版本元数据、CHANGELOG 和发布审计记录。

## 不变边界

- 不改变 ASR provider 选择、豆包协议、阿里云 FunASR 协议、音频采集、最终文本门禁、LLM 触发、剪贴板输出、热键、托盘、统计或日志脱敏行为。
- 不新增、不删除、不迁移配置字段。
- 不新增运行时依赖。
- 不记录真实密钥、识别正文、热词、prompt、最近上下文正文、屏幕 OCR 正文或 Windows 用户名路径。

## 验证结果

- `npm ci`：通过。
- `npm run audit:npm`：通过，0 个 npm 漏洞。
- `npm run ai:check`：通过，包含前端构建、密钥扫描、治理检查、Rust fmt/check/test，Rust 单元测试 218 个通过。
- `npm run ai:release-check`：通过，包含本地检查、npm audit、Rust audit、clippy 和 Tauri debug build；Rust audit 仅报告既有允许的 17 条上游 warning。
- `npx tauri build`：通过。

## 发布产物

- Windows x64 NSIS 安装包：
  `src-tauri/target/release/bundle/nsis/VoxType_0.6.2_x64-setup.exe`

## 手工回归建议

- 打开应用确认版本号为 `0.6.2`。
- 触发一次豆包或阿里云连接测试，确认 CI 治理改动没有影响 ASR 配置入口。
- 后续依赖升级时优先运行 `npm run ai:release-check`，避免本地和远端检查再次漂移。
