# VoxType 0.2.2 发布审计

日期：2026-07-03

## 发布范围

- 成功识别并输出文本后，隐藏 `low_activity` 录音质量警告，避免麦克风电平较低但豆包 ASR 已正常返回时反复误提醒。
- 失败、空识别、低音量和削波等排障提示不变。
- 同步 README、英文 README、Wiki、CHANGELOG 和版本元数据。

## 版本号选择

- 本次是用户可见体验修复，不涉及配置结构、数据格式或安装路径变化。
- 按版本号策略递增 patch，从 `0.2.1` 发布为 `0.2.2`。

## 主链路审计

- 只调整首页录音质量提示的展示条件，不改 ASR 请求、音频采集、LLM、剪贴板、热键、托盘、统计或日志链路。
- 成功态仍来自既有 `lastSessionOutcome.kind === "success"`，不会让空识别进入成功态。
- 录音质量诊断仍只展示 RMS、峰值、有效语音比例和时长等非正文指标，不新增识别正文日志或诊断输出。

## 手工回归建议

- 成功识别并输出文本但录音质量为 `low_activity` 时，首页不再显示“有效语音偏少”提示。
- 空识别或识别失败时，首页仍显示录音排障提示。
- `low_volume`、`clipping` 等更明确的音频质量问题仍显示提示。
