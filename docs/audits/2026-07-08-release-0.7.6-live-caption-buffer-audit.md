# VoxType 0.7.6 发布审计

日期：2026-07-08

## 版本判断

本次从 `0.7.5` 升到 `0.7.6`。原因是修复实时字幕在长文本识别过程中被 ASR 短尾段覆盖的问题，属于用户可见显示体验修复；不涉及配置迁移、最终文本输出、LLM 润色、剪贴板、统计或日志结构，按版本策略递增 patch。

## 修复与改进

- 新增实时字幕显示缓冲：同一轮录音内，如果新字幕只是上一条更完整字幕的明显更短子串，不再覆盖当前悬浮字幕。
- 豆包和阿里云 ASR 的实时字幕发送点共用同一缓冲逻辑，两个 provider 的显示行为保持一致。
- 非重叠短文本和更完整的新字幕仍会正常显示，避免把真实新内容误判为旧上下文。

## 主链路审计

- 本次只改变实时字幕显示反馈，不改变最终 ASR 结果选择。
- 中间 ASR 文本仍不会进入 LLM 润色、自动粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败态、最终包门禁、日志脱敏、统计不记录正文、最近上下文不写回配置的规则未变。
- 不新增、删除或修改配置字段，不需要配置迁移。
