## Changes

- 新增 `llm_post_edit.thinking_strategy`，默认 `auto`，用于按服务商适配关闭 thinking/reasoning 的请求字段。
- API 配置页新增“思考适配”选择项；大模型连接测试会尝试候选策略，保存耗时最短的成功结果。
- LLM 润色和自动热词生成共用同一套请求适配逻辑，覆盖 DashScope `enable_thinking=false`、DeepSeek/MiMo `thinking.type=disabled`、OpenRouter 低 reasoning effort 和省略字段兜底。
- 配置模板、README、英文 README、Wiki 草稿和三语言文案同步说明思考适配策略。
