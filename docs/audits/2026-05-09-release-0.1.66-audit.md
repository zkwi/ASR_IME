## 结论

- 隐私边界已从诊断说明前置为可见产品能力：用户可以在独立页面看到保存位置、上传边界、开关状态和清理入口；页面只展示计数和逻辑路径，不展示识别正文、OCR 正文、热词历史正文、prompt 或密钥。
- 本地清理能力覆盖最近上下文、自动热词历史和使用统计。审计中发现并修复了统计清空只删除当前命中统计文件的问题；现在会清理所有候选 `voice_input_stats.jsonl`，避免刷新后读回旧记录。
- 托盘右键菜单已增加问题反馈入口，使用系统浏览器打开 GitHub Issue 反馈页面；托盘左键单击和双击都会打开主窗口，双击兼容保留。
- 选项页把主快捷键、鼠标中键和右 Alt 放到同一“输入触发”分组，关闭窗口和开机启动移入“启动与窗口”，设置结构更清晰。
- 文档已同步说明隐私与本地数据页、统计清空、第三方 ASR/LLM 留存边界、托盘单击和问题反馈入口；`docs/architecture.md` 补充了主链路、generation、防旧 worker、剪贴板恢复、统计口径、配置路径和 ASR/LLM/OCR 数据流。
- 本次不改配置结构、ASR 请求协议、LLM 润色触发条件、剪贴板输出策略、热键默认值、统计正文记录或日志脱敏策略。
- `npm run ai:release-check` 通过；Rust 审计仅报告当前 Tauri 依赖链中已允许的 19 条上游 warning。
- `npm run audit:npm` 未发现 npm 漏洞。
- `npx tauri build` 已生成 Windows x64 NSIS 安装包：`VoxType_0.1.66_x64-setup.exe`。
