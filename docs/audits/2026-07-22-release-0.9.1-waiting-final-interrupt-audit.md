# VoxType 0.9.1 发布审计

日期：2026-07-22

## 版本判断

本次从 `0.9.0` 升到 `0.9.1`。改动只修复等待最终识别结果时无法通过输入触发键脱困的问题，没有新增配置字段、数据格式、安装路径或兼容性变化，符合 patch 版本范围。

## 实现范围

- 等待最终结果时，再按任一已启用的输入触发键会中断旧会话并立即开始新录音。
- 中断操作先使旧 generation 失效；旧 ASR worker 即使稍后返回，也不能继续进入润色、粘贴或成功统计。
- 正在启动、正在停止、正在润色和正在粘贴阶段保持原有保护，不扩大可中断范围。

## 主链路、配置与隐私审计

- 不修改豆包最终包门禁、阿里云 `task-finished` 门禁、ASR 音频分片、停录尾音窗口或 LLM 触发条件。
- 不新增或迁移配置字段，不改变热键、鼠标中键、右 Alt、系统静音或最近上下文默认值。
- 不把识别正文、OCR、热词、prompt 或最近上下文写入日志、统计、诊断报告或本审计。
- 被中断会话不触发粘贴、最近上下文、自动热词历史或成功统计。

## 建议手工回归

- 停止录音并进入“正在等待最后一句识别完成”后，再按主快捷键，确认立即开始新录音。
- 分别使用已启用的鼠标中键和右 Alt 重复上述流程，确认触发行为一致。
- 中断旧会话后继续等待，确认旧会话迟到的最终结果不会突然粘贴或覆盖新会话状态。
- 正在润色或正在粘贴时按触发键，确认仍保留原有保护，避免中途破坏输出链路。

真实 ASR、LLM、剪贴板自动粘贴和托盘全路径仍建议在安装包上手工回归；自动测试不使用用户云端凭据，也不记录真实识别正文。
