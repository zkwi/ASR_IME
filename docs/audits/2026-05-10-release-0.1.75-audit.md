## Changes

- Optimized English page naming and wording around Prompts, recognition terms, Services, and screen text context.
- Reduced History summary card size and spacing to avoid unnecessary wrapping at the default window size.
- Added `screen_context.capture_scope`, defaulting to current display capture with an option for current-window-only OCR.
- Updated README, English README, Wiki drafts, and config template for the new OCR range behavior and privacy boundary.

## Verification

- `npm run ai:release-check` passed, including frontend check/build, stats tests, secret scans, governance checks, Rust fmt/check/tests, Rust audit, clippy, and Tauri debug build.
- Rust audit reported only existing allowed dependency warnings from the Tauri dependency tree.
- `npx tauri build` produced the Windows x64 NSIS installer.

## Scope audit
