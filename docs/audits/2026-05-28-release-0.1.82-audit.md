## Changes

- 统计分析页将中文输入速度估算说明移动到“节省时间”卡片，并收紧汇总卡片的响应式布局。
- 选项页新增顶部快捷跳转区，可快速定位启动、麦克风、输入结果、屏幕文字、悬浮字幕和更新诊断设置。
- 左侧页面切换时会自动回到新页面顶部，避免长页面滚动位置影响下一页阅读。
- 标题栏“最小化到托盘”按钮改用托盘收起语义更明确的图标。
