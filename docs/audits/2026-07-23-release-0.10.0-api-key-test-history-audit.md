# VoxType 0.10.0 发布审计

日期：2026-07-23

## 版本判断

本次从 `0.9.1` 升到 `0.10.0`。改动新增 API Key 显示、隐藏与复制交互，并在大模型配置页持久展示最近连接测试表现，属于明显的用户可见功能和设置页体验扩展；没有破坏配置兼容性，因此按项目版本策略升级 minor。

## 实现范围

- 豆包 Access Key、阿里云 API Key 和大模型 API Key 默认隐藏，输入框右侧提供显示、隐藏和复制操作。
- 复制成功或失败通过图标、按钮标签和辅助技术可读状态反馈，不在日志中输出密钥。
- 大模型配置页保留最近 5 次自动或手动连接测试，展示成功率、成功请求平均延迟和最近一次结果。
- 失败测试参与成功率计算，但不作为 `0 ms` 计入平均延迟；缺少延迟的旧式成功结果仍计为成功。
- 宽屏使用“模型 / 最近测试表现”左右布局，窄窗口退回单列。

## 主链路、配置与隐私审计

- 不修改录音、ASR 最终包、LLM 润色触发、剪贴板粘贴与恢复、最近上下文、自动热词或成功统计链路。
- 不新增 `config.toml` 字段，不改变最近上下文、右 Alt、鼠标中键、系统静音或日志正文默认策略。
- 测试历史仅在 WebView 本地存储中保存测试时间、成功或失败结果与延迟，不保存 API Key、Base URL、模型名或测试文本。
- 持久化数据加载时只接受布尔结果和非负数值，忽略额外字段与异常记录，避免把密钥或其他意外字段带回应用状态。

## 建议手工回归

- 在桌面应用中分别验证豆包 Access Key、阿里云 API Key 和大模型 API Key 默认遮蔽、显示、再次隐藏与复制。
- 连续执行 5 次以上大模型连接测试，覆盖成功和失败，确认只保留最近 5 次且成功率、平均延迟与最近一次结果正确。
- 重启应用后确认测试摘要仍可查看，切换简体中文、繁體中文与 English 确认文案完整。
- 使用真实大模型凭据完成一次手动连接测试，并确认测试摘要不会影响自动保存、润色或主语音输入链路。

真实云端连接、录音、粘贴和安装包运行仍需在用户环境中手工回归；自动测试不使用用户云端凭据，也不记录真实密钥、识别正文或测试文本。
