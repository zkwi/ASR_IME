# VoxType 0.8.2 发布审计

日期：2026-07-18

## 版本判断

本次从 `0.8.1` 升到 `0.8.2`。改动修复悬浮字幕预览对 ASR 格式性换行和连续空白处理不当的问题，属于小范围用户可见缺陷修复；不涉及配置迁移、数据格式变化、安装路径变化或主链路兼容性，按项目版本策略使用 patch 版本。

## 根因与修复

- 原预览归一化保留 `\r`、`\n` 和空白行，布局又把显式换行视为双行信号；连续换行留下的空白行会占用最多两行中的一个显示名额。
- `normalizeOverlayText` 现在只在预览边界把连续空白压缩成一个普通空格，再复用现有中文空格与标点清理规则。
- 后续布局仍按清理后的文本长度、真实宽度和可用高度选择一行或两行；字号、两行上限、窗口最低高度和 DOM/CSS 均未改变。

## 主链路、配置与隐私审计

- 本次只修改实时字幕预览字符串，不修改豆包或阿里云 ASR 请求、响应解析、最终包门禁和最终文本选择。
- 不改变 LLM 润色、剪贴板写入与恢复、自动粘贴、最近上下文、自动热词、统计、热键、托盘或日志。
- 不新增配置字段、依赖、用户可见文案 key 或配置迁移。
- 测试使用合成文本；识别正文不写入日志、诊断报告、统计、文档或发布资产。
