# VoxType 0.6.4 发布审计

日期：2026-07-07

## 版本号选择

本次从 `0.6.3` 升到 `0.6.4`。原因是本轮专门处理豆包 WebSocket ASR 核心文件过大的维护风险：只做工程结构拆分和文档同步，不新增用户功能、不改变配置结构和主链路策略，按版本策略属于 patch 发布。

## 本轮问题整理

- `src-tauri/src/asr_ws.rs` 同时包含 worker 编排、豆包 WebSocket 会话、音频发送节奏、最终文本选择、实时字幕节流、输出事件和错误映射，单文件超过维护舒适区。
- ASR 主链路属于高风险区域，继续在单一大文件里追加阿里云/豆包相关适配会增加误改最终文本门禁、空识别失败态和输出副作用的概率。
- 原有单元测试覆盖了关键 ASR 边界，但测试和实现混在同一大文件里，后续定位失败原因不够直接。

## 改动范围

- 将 `src-tauri/src/asr_ws.rs` 改为 `src-tauri/src/asr_ws/` 目录模块。
- `mod.rs` 只保留模块声明和原有对外导出，避免影响 `asr_provider.rs`、`aliyun_asr.rs` 和 session 调用方。
- `worker.rs` 保留 ASR worker 编排和 LLM 润色延迟状态。
- `session.rs` 保留豆包 WebSocket 正式识别会话循环。
- `audio_stream.rs` 保留音频队列、首包静音 padding、发送节奏和测试音频。
- `connection.rs` 保留连接测试和握手等待。
- `final_text.rs` 保留二遍分句、最终包选择、等待最终包和超时判断。
- `partial_text.rs` 保留实时字幕归一化和节流。
- `output.rs` 保留最终文本事件、空识别失败态、输出成功副作用和提示 hold 规则。
- `errors.rs` 保留错误码归类、服务错误和连接错误友好提示。

## 不变边界

- 不改变豆包 ASR payload、音频分片默认值、最终包等待策略、二遍分句选择策略或实时字幕节流策略。
- 不改变阿里云 FunASR、LLM 润色、剪贴板输出、热键、托盘、统计和日志脱敏行为。
- 不新增、不删除、不迁移配置字段。
- 不新增项目依赖。
- 不记录真实密钥、识别正文、热词、prompt、最近上下文正文、屏幕 OCR 正文或 Windows 用户名路径。

## 手工回归建议

- 使用豆包 ASR 做一次短句和一次长句输入，确认实时字幕、最终文本、LLM 润色和自动粘贴仍正常。
- 做一次空识别或静音输入，确认进入失败态，不触发粘贴和成功统计。
- 切换到阿里云 FunASR 做一次连接测试，确认 provider 入口未受豆包目录化影响。
