# VoxType 0.7.7 发布审计

日期：2026-07-08

## 版本判断

本次从 `0.7.6` 升到 `0.7.7`。原因是继续修复悬浮字幕显示层的用户可见问题，并收敛上一轮仍偏复杂的布局状态机。改动不涉及配置迁移、ASR provider 协议、最终文本门禁、LLM 润色、剪贴板输出或统计数据结构，按版本策略递增 patch。

## 修复与改进

- 移除悬浮字幕显示中的历史锁定状态，避免上一条双行字幕影响下一条单行字幕字号。
- 移除悬浮字幕定时滚动，超过两行时只显示最新两行，避免实时字幕自动滚动造成换行错位。
- 将双行字号上限收敛到不超过单行最小字号，避免双行文本反而比单行文本更大的视觉反常。
- 字幕布局改为一次性计算：短且能放下一行就显示一行，否则在高度允许时显示最多两行。

## 主链路审计

- 本次只改变悬浮字幕显示布局，不改变 ASR 请求、最终文本选择、LLM 润色、剪贴板输出、最近上下文、自动热词或统计逻辑。
- 实时字幕和中间包仍只用于显示反馈，不进入润色、粘贴、最近上下文、自动热词历史或成功统计。
- 空识别失败、最终包门禁、日志脱敏、统计不记录正文、最近上下文不写回配置的规则未变。
- 不新增、删除或修改配置字段，不需要配置迁移。
