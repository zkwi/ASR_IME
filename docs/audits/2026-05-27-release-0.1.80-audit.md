## Changes

- 大模型润色新增可选“润色时参考最近上下文”，默认关闭。
- LLM 最近上下文需要同时开启本地最近上下文和 LLM 最近上下文开关，且仅在润色实际触发时附加到请求。
- 最近上下文作为独立参考信息块发送给大模型，并限制为最新片段的约 600 字内容，避免被当作待润色文本或指令。
- LLM 连接测试不读取或上传本地最近上下文。
- 热词与提示词页、隐私与本地数据页、提示词预览、配置模板、README、英文 README、Wiki 草稿和架构说明同步更新隐私边界与使用说明。
