## Changes

- 默认大模型 System Prompt 增加输入结构优先级和技术文本规则，明确待润色文本是唯一输出来源。
- 默认 User Prompt Template 增加待润色文本边界，降低参考信息被误当作正文的概率。
- LLM 润色参考信息拼装补充最近上下文、屏幕 OCR、文件路径、命令、日志字段和代码标识符限制。
- 配置模板、前端默认值、README、英文 README 和 Wiki 草稿同步说明 prompt 拼装边界。
- 本地 VoxType 配置已同步新的默认 prompt，并保留本地备份文件。
