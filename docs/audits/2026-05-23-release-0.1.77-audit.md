## Changes

- Renamed the former service configuration surface to API Config across UI copy, error guidance, README, and Wiki drafts.
- Added an official Doubao ASR documentation entry from the Doubao credentials panel to reduce first-time setup friction.
- Updated the LLM API test to send sample text with the real AI prompt and return measured latency on success.
- Reordered Hotwords & prompts so recognition terms and writing context appear before AI prompt editing, and removed the collapsed prompt editor state.
- Reorganized Options into common settings, enhancements, and maintenance, while keeping Privacy & local data as a sidebar page instead of a duplicate options card.

## Verification

- `npm run ai:release-check` passed, including frontend check/build, stats tests, secret scans, governance checks, Rust fmt/check/tests, Rust audit, clippy, and Tauri debug build.
- Rust audit reported only existing allowed dependency warnings from the Tauri dependency tree.
- `npx tauri build` produced the Windows x64 NSIS installer.
