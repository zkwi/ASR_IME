# VoxType release audit - 2026-06-08

Version: 0.1.104

## Scope

- Fix final text selection so a highly overlapping Doubao final `result.text` can still win when it recovers tail words but slightly shortens earlier wording.
- Keep the guard against obviously incomplete final packets, so a very short final `result.text` does not overwrite fuller `definite=true` utterances.
- Increase default stop-tail capture from about `150ms` to about `250ms`, capped at about `400ms` when voice remains recent.
- Migrate old default `stop_grace_ms` values `800`, `200`, `150`, and `100` to the new `250` default.
- Sync README, English README, config example, Wiki drafts, ASR guardrails, audio-fragment audit, changelog, version metadata, and release documentation.

## Main Flow Guardrails

- Final output still requires Doubao's final package; interim ASR text remains feedback only.
- Live captions can still show interim text quickly, but paste, LLM post-edit, recent context, hotword history, and success stats only use final text.
- Any partial final audio chunk is flushed before the microphone closes, and the last real audio packet is sent as the negative final packet.
- No trailing silence is appended after recording stops.
- The default ASR packet size remains `200ms` and stays within Doubao's recommended `100-200ms` range.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, statistics text policy, log redaction, or config field structure.
