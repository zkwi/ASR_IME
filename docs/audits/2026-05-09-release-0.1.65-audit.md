# VoxType release audit - 2026-05-09

本记录用于保存 `0.1.65` 发布前审计的非敏感结论。不要在审计记录中写入真实密钥、识别正文、屏幕 OCR 正文、热词、prompt、最近上下文、日志正文或本机用户名路径。

## 范围

- README、README.en.md、仓库文档和 `docs/wiki/` 本地 Wiki 草稿的截图与说明同步。
- 工程治理检查脚本、统计口径回归测试和 CI / `ai:check` 接入。
- 首页统计卡片中“节省时间”的 24 小时、7 日和按日统计口径。
- 前端主 controller 的通知与统计职责拆分。
- `text_output.rs` 中 Win32 剪贴板和全局内存资源边界的 RAII 化。
- 版本号、CHANGELOG、发布检查和安装包产物。

## 结论

- 文档覆盖面有明显提升：README、英文 README、Wiki 草稿和仓库内文档索引现在能相互指向，截图引用也纳入自动检查，后续更不容易出现 README、Wiki 和本地文档漂移。
- 工程治理从人工约定前移到自动化检查：`package.json`、`package-lock.json`、Tauri 和 Cargo 版本一致性、Markdown 本地链接、截图引用和 Wiki 镜像覆盖进入 `npm run check:governance`，并由 `npm run ai:check` 与 CI 执行。
- 统计“节省时间”已统一为净节省时间，即“手打等效时间 - 实际语音时长”；最近 24 小时不再把手打等效时间误展示成节省时间。
- `VoxTypeController.svelte.ts` 已把通知和统计两类横切职责拆到独立 controller，主 controller 仍保留组合入口职责，避免为了拆分而引入复杂依赖或过度抽象。
- 剪贴板输出路径使用 `ClipboardGuard`、`OwnedGlobalMemory` 和 `LockedMemory` 收敛 `OpenClipboard` / `CloseClipboard`、`GlobalAlloc` / `GlobalFree`、`GlobalLock` / `GlobalUnlock` 边界；`SetClipboardData` 成功后显式转移所有权，避免后续维护时误释放。
- 本次不改配置结构、默认值、ASR 请求、LLM 触发条件、热键默认策略、托盘、统计正文记录或日志脱敏。
- `npm run ai:release-check` 通过；Rust 审计仅报告当前 Tauri 依赖链中已允许的 warnings。
- `npx tauri build` 已生成 Windows x64 NSIS 安装包：`VoxType_0.1.65_x64-setup.exe`。
- 安装包 SHA256：`8B856300C3D65608BC9ADECD5E41BD53D5453EBC2AD819FE41A086729CB9BD2A`。
