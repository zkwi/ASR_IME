# VoxType 0.8.0 发布审计

日期：2026-07-13

## 版本判断

本次从 `0.7.9` 升到 `0.8.0`。改动同时覆盖 DashScope 思考模式兼容、LLM 客户端复用、前端测试体系、安全策略、CI 性能和 TLS 传输栈，属于用户可感知的性能修复与持续工程改进，按项目版本策略发布 minor 版本。

## 修复与改进

- DashScope 关闭思考时固定发送 `enable_thinking=false`，不再把省略字段误判为成功关闭；已知仅思考模型会在调用前给出明确提示，避免无效慢请求。
- `llm_post_edit` 与自动热词生成复用同一套 OpenAI 兼容 HTTP 客户端、请求体、思考策略回退和响应解析逻辑，保持业务 prompt 与过滤逻辑不变。
- 前端纯函数测试迁移至 Vitest，覆盖字幕布局、统计、设置状态、错误路由、热词和会话状态。
- Tauri WebView 启用本地资源 CSP；CI 增加 Rust 构建缓存并使用预编译 `cargo-audit`。
- HTTP 与 WebSocket 客户端统一使用 rustls，移除 native-tls 及其重复依赖。

## 主链路、配置与隐私审计

- DashScope 已知仅思考模型在关闭思考时会跳过 LLM 润色；ASR、最终包门禁、剪贴板、热键、托盘、统计和日志规则不变。
- 未新增或迁移用户配置字段，现有配置文件保持兼容。
- 未新增正文、密钥、热词、prompt、最近上下文或用户路径日志。
- TLS 改动使用项目内短静音包连接测试分别验证豆包和阿里云，不采集麦克风，不输出凭据。
