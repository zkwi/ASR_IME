# VoxType release audit - 2026-06-27

Version: 0.1.107

## Scope

- Keep Doubao ASR language on service default by default and migrate the legacy `zh-CN` default to an empty value.
- Add local microphone input gain calibration based on PCM RMS, peak, active speech ratio, and duration.
- Add a lightweight latest-recording quality card with RMS, peak, active speech ratio, clipping suspicion, duration, and actionable advice.
- Keep the recording quality card out of the main statistics table and avoid storing transcript text.
- Update the locked `quinn-proto` transitive dependency to `0.11.15` to clear the release-blocking RustSec advisory.
- Sync changelog, version metadata, README, English README, Wiki drafts, configuration example, i18n text, and release documentation.

## Verification

- `cargo test audio::tests::gain_calibration`
- `cargo test audio::tests::audio_quality`
- `npm run ai:check`
- `npm run ai:release-check`
- `npx tauri build`

## Main Flow Guardrails

- Final output still requires Doubao's final package; realtime and intermediate ASR text remain display feedback only.
- This release does not change ASR audio packet timing; the default audio segment remains `200ms` within Doubao's recommended `100-200ms` range.
- Recording quality diagnostics contain only non-transcript metrics and are not written to the main statistics table.
- Gain calibration analyzes local microphone PCM only; it does not save audio files or upload calibration audio outside the existing ASR flow.
- This release does not change LLM post-edit trigger conditions, clipboard write/restore behavior, hotkey defaults, tray behavior, log redaction, or config field structure.
- The RustSec dependency update is lockfile-only and does not change runtime feature flags.
