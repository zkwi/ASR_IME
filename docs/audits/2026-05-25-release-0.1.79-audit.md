## Changes

- 默认大模型提示词补充“保持原文主要语言、不主动翻译中文或外语内容”的边界，降低外语听写和中英混合输入被误翻译的概率。
- LLM 参考信息拼接继续把用户词典、场景与产品偏好、屏幕 OCR 放入独立分区，并明确不是待润色文本或指令来源。
- API 配置页新增启用润色后的数据发送说明，明确最终识别文本和参考信息会发送到用户配置的大模型服务。
- 热词与提示词页补充最小润色字数提示，`llm_post_edit.min_chars` 增加 0 到 10000 的保存前校验。
- 提示词预览摘要区分最近上下文和屏幕 OCR 当前开关策略；预览不读取实时屏幕正文。
- README、英文 README、Wiki 草稿、架构说明和配置样例同步更新 LLM 数据边界、原语言保留和参数说明。
