## Changes

- 修复悬浮字幕透明度设置可能不透出桌面背景的问题，显式设置字幕窗口和 WebView 底层透明背景。
- 为 overlay/toast 页面补充明确的 `data-voxtype-mode` 模式标记，避免透明背景只依赖 `:has()` 选择器。
- 排查同类透明窗口路径：当前 `startup-toast` capability 保留，但启动提示实际只写日志；前端 toast 样式已被模式标记覆盖。
