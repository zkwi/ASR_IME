# VoxType release audit - 2026-07-03

Version: 0.1.109

## Scope

- Move screen OCR capture and recognition into the OCR worker thread so capture failures or slow OCR do not block recording startup before the configured wait path.
- Reduce the default LLM polishing context budget:
  - `min_chars = 80`
  - `reference_hotwords_limit = 50`
  - `recent_context_max_chars = 200`
  - `screen_context_max_lines = 12`
  - `screen_context_max_chars = 400`
- Keep ASR screen OCR context unchanged: ASR still uses `[screen_context].max_chars`, while LLM polishing uses its own smaller reference budget.
- Sync Rust defaults, validation, config migration, frontend settings, i18n text, config example, README files, Wiki drafts, guardrail docs, changelog, and version metadata.
- Update Tauri patch-level dependencies where compatible. `plist 1.9.0` still pins `quick-xml` below RustSec's fixed `0.41.0` line, so `RUSTSEC-2026-0194` and `RUSTSEC-2026-0195` are explicitly ignored in the release audit script until upstream releases a compatible fix. VoxType does not parse untrusted plist/XML at runtime.

## Performance Check

- Formal-environment log review showed recent OCR around a few hundred milliseconds and not the main bottleneck. Sessions with LLM polishing were materially slower than sessions without LLM polishing.
- Synthetic LLM comparison used the configured formal LLM endpoint with synthetic text only. No API key, prompt body, OCR body, hotwords, recent context, transcript, or local log content was printed or saved.
- Baseline synthetic prompt: average `4370` prompt chars, `4753ms` over 2 successful requests.
- Compacted synthetic prompt: average `1579` prompt chars, `4068ms` over 2 successful requests.

## Main Flow Guardrails

- Empty recognition still fails and does not trigger polishing, paste, recent context, hotword history, or success stats.
- Final output still waits for Doubao's final package; realtime and intermediate ASR text remain feedback only.
- This release does not change ASR audio packet timing; the default audio segment remains `200ms` within Doubao's recommended `100-200ms` range.
- Screen OCR timeout still skips optional context rather than blocking final recognition or paste.
- LLM polishing still only runs when enabled, text reaches `min_chars`, and Base URL, API Key, and model are complete.
- No transcript text, hotwords, prompt content, recent context, screen OCR text, local log body, Windows username path, or secrets are written to this audit.
